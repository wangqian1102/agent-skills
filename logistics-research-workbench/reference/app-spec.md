# 工作台网页规格

单页应用（原生 HTML/CSS/JS，无构建步骤），入口 `index.html`，数据在 `data.js`。

## 文件结构

```
project/
├── index.html    # 页面结构与样式
├── app.js        # 向导流程、状态管理、主备选分配、Word导出
├── data.js       # window.CITY_DATA 城市知识库（结构见 knowledge-base-schema.md）
└── docx.umd.js   # docx.js 本地打包（禁用 CDN，随项目目录一起交付）
```

## 省市区选择

- 省份下拉：内置安徽省（含已有知识库城市的省份）；城市下拉联动 `CITY_DATA.cities` 的键；区县下拉取 `overview.districts` ＋ 功能区（高新区/经开区等）
- 片区/乡镇二级下拉：联动 `overview.subLocations[区县]`，可选；初始化时必须先设 state.city 再填两级下拉（否则首屏区县为空的 bug）
- 地块选址：文本输入，标注"可选，未定可跳过"

## 6步向导

顶部步骤条（1 基本信息 → 2 城市总览 → 3 产业勾选 → 4 物流园区 → 5 快递节点 → 6 政府部门 → 汇总），支持前进/后退，不强制顺序。

### 第2步 城市总览
按 overview 各模块分卡片展示：行政区划（含区县标签）、物流枢纽定位、快递订单体量（数值突出显示）、产业概述（表格：产业/规模/全国地位/代表企业）、用仓需求企业（按 demandLevel 排序）、园区定位建议（方向+理由）。关键数据旁小字标注来源。

### 第3步 产业勾选 + 主备选
- 每个产业卡片：勾选开关 + 目标调研企业数 N（数字输入，默认 3，同时监听 input+change 事件——点击步进按钮须实时生效）+ 该产业 note（含可调研企业数）
- 勾选产业后展开企业列表：每个企业行首有"是否调研"勾选框（默认全选，取消即从主备选与导出中剔除）；按 tier 排序，前 N 家标"主选"，其后 ceil(N/2) 家标"备选"，每行有"调换主备选"按钮
- N 变更或企业勾选变化时实时重算主备选
- 商贸流通企业（surveyCommerce，按细分领域分组）同页第二区块处理，逻辑相同

### 第4步 物流园区
物流市场总览（来自 overview）+ 园区列表按 现存/在建/规划 分组，每行：勾选框、名称、位置、定位。

### 第5步 快递节点
按品牌分组，每个节点行：勾选框、品牌、节点类型徽标（分拨中心/集配站/站点）、具体地点。

### 第6步 政府部门
按部门卡片，每条调研内容一行勾选框，默认全部勾选；旁注"已获取的可取消勾选"。卡片头部显示部门名与调研目的。

### 汇总页
统计：勾选产业数、主选/备选企业数、园区数、快递节点数、政府部门保留条目数；分组清单总览；「导出 Word 调研计划」按钮。

## 状态管理

- 所有状态存 `localStorage`，键 `surveyPlanState`（含基本信息输入、各处勾选、每个产业的 N、主备选调换记录）
- 页面加载时恢复；提供「重置」按钮（需二次确认）
- 切换城市时提示"切换将清空勾选状态"

## 主备选分配算法

```
function assignPrimaryBackup(firms, N) {
  const sorted = [...firms].sort((a, b) => a.tier - b.tier);
  return {
    primary: sorted.slice(0, N),
    backup: sorted.slice(N, N + Math.ceil(N / 2))
  };
}
```

## Word 导出（客户端）

- 用 docx.js 生成 .docx 并下载；**必须本地打包**：docx.umd.js 放项目目录、index.html 引用 `<script src="docx.umd.js"></script>`，禁用 unpkg/jsdelivr 等 CDN（国内网络不稳定会导致导出按钮无反应、找不到导出文件）
- 验证方式：Node 原生环境 require docx.umd.js 跑同一套文档构造代码（Packer.toBuffer）生成 .docx，用 python zipfile 校验 zip 完整性、[Content_Types].xml 与 document.xml 存在及关键内容；jsdom 的 Blob/toBlob 不回调，不能用于验证导出
- 文档结构对齐参考文档《宣城项目调研计划》：
  1. **一、拟调研时间**：调研时间段、周期
  2. **二、调研人员及行程初步计划**：表格（调研时间/调研团队/调研目标/调研内容）
  3. **三、前置性收集相关材料**：按勾选部门，每个部门一段：部门名+调研目的，条目编号 (1)(2)(3)…
  4. **四、拟调研企业清单**：四大类（本地产业企业/商贸流通企业/快递物流企业/物流园区），每类开头写调研对象、受访人员、调研内容（取自参考文档模板），然后表格：类别｜企业/园区名｜地点｜主选/备选
  5. 结尾注明数据来源与生成日期
- 文件名：`{城市}项目调研计划_{YYYYMMDD}.docx`
- 表格需同时设置 columnWidths（DXA）与单元格 width；中文用宋体/微软雅黑，标题用 HeadingLevel

## 视觉

- 中文界面；简洁扁平风格，白底卡片；主色深蓝；勾选行有 hover 反馈；步骤条显示完成状态
- 移动端可用（媒体查询，表格可横向滚动即可，不做深度适配）

## 发布

- QW Pages 发布 static 类别，`file_path` 指向项目目录；发布在"访问控制"环节反复报错时不要连续重试——先本地交付（http.server 起本地预览）并提示用户在桌面端确认发布权限后再试
- 发布后告知用户 URL，并验证流程走通
